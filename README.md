# Abarrotes — Inventario

Aplicación web para manejar el inventario y las ventas de una tienda de abarrotes, pensada para usarse desde el celular.

- **Vender**: toca los productos para armar la venta, ajusta con − / + y cobra; el inventario se descuenta al cobrar.
- **Inventario**: agregar, editar, eliminar y surtir productos. Muestra el valor total y avisa cuando hay stock bajo (≤ 10) o agotado.
- **Ventas**: historial de cada venta y total vendido hoy.

Publicada en claude.ai, los datos se guardan en línea (se ven en todos tus dispositivos). Si abres `index.html` directamente en un navegador, funciona en modo local y guarda los datos solo en ese navegador.

Inventario inicial: Todo Rico Original ($4.500 × 32), Todo Rico BBQ ($4.500 × 32), Chicles ($1.500 × 48), Choco Ramo ($4.000 × 45), Bombón ($600 × 48), Jet ($1.500 × 100), Golpe ($2.500 × 48), Papas Margarita ($2.000 × 24).
