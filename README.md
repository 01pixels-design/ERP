# Abarrotes — Inventario

Aplicación web sencilla para manejar el inventario y las ventas de una tienda de abarrotes.

Abre `index.html` en cualquier navegador; no necesita instalación. Los datos se guardan en el navegador (localStorage).

- **Inventario**: agregar, editar, eliminar y surtir productos. Muestra el valor total y avisa cuando hay stock bajo (≤ 10) o agotado.
- **Vender**: carrito de venta que descuenta del inventario al cobrar.
- **Historial de ventas**: registro de cada venta y total vendido hoy.

Inventario inicial: Todo Rico Original ($4.500 × 32), Todo Rico BBQ ($4.500 × 32), Chicles ($1.500 × 48), Choco Ramo ($4.000 × 45), Bombón ($600 × 48), Jet ($1.500 × 100), Golpe ($2.500 × 48).
